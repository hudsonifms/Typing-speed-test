# Análise de Avaliação — Frontend Mentor · Typing Speed Test

Documento de auditoria. Lista **todos os critérios usados pelo Frontend Mentor** para avaliar
uma solução, o diagnóstico do projeto em cada um deles e a correção aplicada.

- **Desafio:** Typing Speed Test (nível Advanced)
- **Auditoria:** 16/09/2026
- **Escopo:** HTML, CSS e JavaScript puros — sem framework, sem build, sem dependências

## Como o Frontend Mentor avalia

A plataforma combina três camadas de avaliação. Esta análise cobre as três.

| Camada | O que é | Como é medida |
| --- | --- | --- |
| **1. Relatório automático** | Roda ao submeter a solução | HTML validator (W3C) + auditoria de acessibilidade (axe-core) |
| **2. Requisitos do desafio** | User stories do `README.md` original | Verificação manual por quem revisa |
| **3. Revisão da comunidade** | Feedback de outros devs e da equipe | Fidelidade ao design, responsividade, qualidade de código, README |
